# Sistema de Vendas – Padaria 2 Corações

## Sobre o projeto
Este projeto tem como objetivo desenvolver um sistema simples para auxiliar no registro e controle de vendas da Padaria 2 Corações, facilitando a rotina dos atendentes.

## Objetivo
Criar uma ferramenta prática e fácil de utilizar, permitindo registrar vendas, consultar informações e organizar os dados.

## Funcionalidades do MVP
- Menu inicial com acesso às funções principais.
- Cadastro de vendas com produto, quantidade, data e valor.
- Confirmação após o registro da venda.
- Opção para iniciar uma nova venda ou voltar ao menu.

## Tecnologias
As tecnologias serão definidas e registradas durante o desenvolvimento do projeto.

## Acessibilidade
O sistema busca oferecer uma interface simples, com textos claros, bom contraste, botões identificáveis e navegação por teclado.
